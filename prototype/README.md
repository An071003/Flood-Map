# Prototype

Mở `index.html` để xem visual/layout prototype.

Đây là **prototype bố cục**, dùng ảnh reference do chủ project cung cấp làm nền minh họa. Các vùng nước, marker và số liệu là mock để thể hiện art direction; không phải dữ liệu địa lý/thời tiết thật.

Mục tiêu của prototype:
- khóa hierarchy desktop;
- khóa palette/token;
- minh họa weather markers nổi trên map;
- minh họa flood water khác nhau theo depth;
- minh họa inspector + forecast timeline.
