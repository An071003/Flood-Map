# Skill: Design Taste Guard

## Trigger
Use whenever creating or reviewing visual UI, especially when the implementation “đúng chức năng nhưng nhìn chưa đẹp”.

## Goal
Giữ sản phẩm có cảm giác cao cấp, rõ ràng, có chiều sâu nhưng không phô diễn hiệu ứng.

## Taste rules
- One focal point per region. Map is the global focal point; selected flood depth is the inspector focal point.
- Prefer fewer, stronger surfaces over many small cards.
- Visual hierarchy comes from spacing, type scale and contrast before shadows/glow.
- Glass blur is seasoning, not the main style.
- Avoid rainbow status palettes outside semantic risk colors.
- Do not center everything; use asymmetric map-first composition.
- Avoid giant gradients behind text or decorative neon borders around every card.
- Large numbers should have breathing room; metadata should be quiet.
- Use consistent icon family and corner radius.
- If an effect does not explain weather, flood, selection or time, remove it.

## Review questions
1. Can a user identify the dangerous area in under 3 seconds?
2. Does the map still look like a map, not a game HUD?
3. Is the inspector readable without zooming?
4. Are weather, water and risk visually distinct?
5. Is there any component that can be removed without losing information? Remove it.
6. Are we using glow/blur because it communicates state or because it looks trendy?
7. Does mobile feel designed rather than merely stacked?

## Output
When doing a design review, report concrete changes grouped as hierarchy, spacing, color, type, motion and map readability. Do not use vague comments like “make it modern”.
