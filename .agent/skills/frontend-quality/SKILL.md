# Skill: Frontend Quality Gate

## Trigger
Use before marking any feature complete.

## Required commands
```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Manual smoke
- 1440×900
- 1280×720
- 390×844
- keyboard
- reduced motion
- provider error
- stale data
- demo badge

Do not mark task done while any mandatory command fails.
