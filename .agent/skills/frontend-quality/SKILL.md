# Frontend Quality Skill

## Scope
- Zustand state architecture: snapshot and restore mechanism (`priorMapStateSnapshot`).
- Mobile responsiveness: bottom sheet drawer states (`collapsed`, `half`, `expanded`) on 390x844 and 360x800 viewports.
- Keyboard navigation and accessibility: `Cmd+K` global search hotkey, escape handling, ARIA roles, sr-only labels.
- Standardized Vietnamese UI copy: consistent terminology across inspector, search modal, routing panel, and error toasts.
- Zero QA/debug controls in production builds.
