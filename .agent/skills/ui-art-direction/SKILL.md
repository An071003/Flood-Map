# UI Art Direction Skill

## Scope
- Dark mode cyber-cartographic aesthetic: deep navy background (`#07111f`), glassmorphic panels (`rgba(13, 27, 42, 0.85)`).
- Visual channel separation:
  - Base roads: muted neutral (`#334155`).
  - Selected route: prominent high-contrast casing (`#ffffff` / `#06b6d4`, 9px) on top layer.
  - Alternatives: semi-transparent muted blue (opacity 0.4).
  - Flood depths: cyan $\rightarrow$ amber $\rightarrow$ orange $\rightarrow$ red.
  - UNKNOWN: dashed neutral slate (`#94a3b8`).
- Micro-animations: GSAP transitions for drawer height, pulse rings on active pins, smooth fitBounds animations.
