# 28 — Mobile UX Spec

## Main principle
Map remains primary.

## Bottom sheet
Collapsed:
- road
- depth
- severity

Half:
- rain
- drainage
- tide
- reason

Expanded:
- vehicle passability
- recommendation
- technical detail

## Interaction
- drag
- snap
- independent scroll
- avoid gesture conflict

## Timeline
Compact horizontal strip.

## Layer controls
Floating menu/button.

## Search
Full-width modal or sheet. Query persistence must remain.
