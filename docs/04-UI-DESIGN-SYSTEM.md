# 04 — UI Design System

## Art direction
- map-centric
- dark
- calm
- credible
- operational
- not cyberpunk
- not card-grid heavy

## Tokens
Xem `docs/design-tokens.json`.

## Severity
- Safe: green + check
- Watch: blue + dot
- Warning: orange + triangle
- Severe: red + exclamation

Không dùng color-only encoding.

## Typography
- UI: Inter/system sans
- Numeric metric: tabular numerals
- Depth metric phải là visual anchor

## Radius
- panel: 16px
- controls: 12px
- pills: 999px khi thật sự cần

## Motion
- 150–250ms micro interactions
- 300–600ms map/3D transitions
- respect `prefers-reduced-motion`

## Don't
- excessive glow
- frosted cards everywhere
- giant gradients
- meaningless particle effects
