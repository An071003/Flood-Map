# V3.3 Technical Spec

## GitHub Pages asset safety
Project deploys under `/Flood-Map/`.

Safer:
```ts
import boundary from './hcmc-boundary.geojson'
```

or:
```ts
const url = new URL('./hcmc-boundary.geojson', import.meta.url)
```

or:
```ts
const url = `${import.meta.env.BASE_URL}data/hcmc-boundary.geojson`
```

Be careful with:
```ts
fetch('/data/hcmc-boundary.geojson')
```

## Boundary validation
Compute bbox before rendering.
If bbox is far outside HCMC, coordinates/projection are wrong.

## Rendering order
1. basemap
2. outside mask
3. boundary fill
4. boundary line
5. roads
6. flood overlays
7. pins/labels

## Stress / cleanup
Three.js:
- one render path
- dispose owned geometry/material/texture
- no duplicate RAF

GSAP:
- kill/replace old tween on rapid timeline changes

MapLibre:
- stable source/layer IDs
- cleanup listeners
- no duplicate source/layer
