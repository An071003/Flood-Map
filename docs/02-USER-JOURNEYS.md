# 02 — User Journeys

## Journey A — Search một đường
1. User click search.
2. Nhập `Nguyễn Hữu Cảnh`.
3. Search results hiển thị roads.
4. User chọn road.
5. Query vẫn nằm trong input.
6. Map zoom/fit đến road.
7. Geometry được highlight.
8. Inspector mở thông tin road.
9. Timeline có thể scrub.

## Journey B — Click trực tiếp trên map
1. User click một road overlay.
2. Map xác định segment gần click.
3. Selected segment highlight.
4. Anchor/popup nằm trên road.
5. Inspector update.

## Journey C — Xem tương lai
1. Chọn road.
2. Drag timeline +3h.
3. UI hiển thị `Đang cập nhật…`.
4. 3D depth transition mượt.
5. Inspector update số liệu.
6. Trend hiển thị rising/stable/decreasing.

## Journey D — Mobile
1. Map full-screen.
2. Search compact.
3. Chọn road.
4. Bottom sheet collapsed hiển thị road + depth + severity.
5. Swipe up để xem detail.
